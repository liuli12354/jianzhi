## 0. 差距审计（对照 Obsidian/Notion/思源）

| 缺口 | 实用性影响 | 本轮对策 |
|---|---|---|
| 网页内容粘贴不转 Markdown | 从浏览器收集资料是知识库第一高频动作，手工转换劝退 | turndown + GFM 插件，粘贴 HTML 自动转 MD |
| 编辑器列表/任务不会自动续行 | 日记与任务场景每行都要手敲 `- [ ]` | Enter 智能续行（含编号递增、空项退出） |
| 只能同时"看"一篇笔记（无标签页） | 交叉查阅多篇笔记来回切换成本高 | 多标签页（打开即建签、×关闭、标题同步） |
| 只有反链没有出链 | 图谱导航不对称 | 出链面板（服务端解析 [[ ]] 求解目标） |
| 任务无日期概念 | GTD 场景分不清逾期/今天 | `📅 YYYY-MM-DD` 约定 + 逾期/今天着色 |
| 代码块无法一键复制 | 技术笔记高频动作 | pre 注入复制按钮（事件委托） |
| 分享单篇只有 .md | 收件人体验差 | 导出独立 HTML（内联样式） |

## 1. 关键决策

1. **HTML 粘贴转 MD**：`turndown` + `turndown-plugin-gfm`（表格/删除线/任务列表）。粘贴事件优先级：文件（图片附件）> `text/html`（转 MD）> 纯文本（默认行为）。转换失败回退纯文本。
2. **Enter 智能续行**：光标行匹配 `- [ ] `/`- [x] `/`- `/`* `/`1. ` 前缀 → 插入同型前缀（编号 +1）；标记后内容为空 → 删除标记退出列表；Shift+Enter 保持默认换行。
3. **多标签页**：v1 采用轻量模型——打开笔记即建签（标题跟随保存同步），点击切换（编辑器按 id 重挂载，与现有点击列表行为一致），× 关闭（关闭激活签时激活邻签）；不做标签拖拽/固定（列 v0.9）。
4. **任务日期**：遵循 Obsidian Tasks 的 `📅 YYYY-MM-DD` 约定（写在任务文本尾部）；服务端解析为 `due` 字段；弹窗任务行显示日期 chip（逾期红/今日橙/未来灰），并新增「逾期」快速筛选。
5. **代码块复制**：markdown 渲染后向每个 `<pre>` 注入复制按钮，`Markdown` 容器用事件委托处理点击（`navigator.clipboard`，成功后按钮短暂变 ✓）。
6. **导出 HTML**：`exportNoteAsHtml`——内联紧凑 Markdown 样式 + 渲染后的正文，独立文件可直接打开/打印。
