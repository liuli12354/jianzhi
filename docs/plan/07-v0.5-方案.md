**过程中修复**：
1. v05 测试的「空库」用例：`db.js` 在模块加载时绑定 DATA_DIR，进程内二次赋值无法隔离，且断言失败时第二个 server 未 close 导致测试进程挂起 → 改为**子进程**（独立 DATA_DIR）验证空库语义，彻底消除泄漏。
2. 测试脚手架缺陷（非应用缺陷）：合成 DnD 的 drop 事件需**复用 dragstart 的 DataTransfer**（真实浏览器自动携带），首次误在 drop 时新建含目标 id 的数据，导致断言错乱；修正后全流程通过。

## 0. 范围与验收标准

| # | 优化项 | 关键决策 | 验收标准 |
|---|---|---|---|
| 1 | 反链整段上下文 | `listBacklinks` 每条附 `contextFull`（命中行 ±3 行窗口，空行压缩）；面板逐条「展开/收起」 | 展开后可见引用行上下文，收起回到单行 |
| 2 | 笔记拖拽换笔记本 | NoteList 条目可拖拽；侧栏笔记本条目接受放置（dataTransfer 自定义类型区分笔记/笔记本两套拖拽）；放置 = `PATCH /notes/:id { notebookId }` | 拖笔记到笔记本完成移动、列表/计数联动、拖拽期间放置目标高亮 |
| 3 | 随机漫游 | `GET /api/notes/random`（活跃笔记 `ORDER BY RANDOM() LIMIT 1`）；顶栏 🎲 按钮 + 命令面板「随机漫游一篇笔记」 | 每次点击打开一篇随机活跃笔记；空库返回 null 前端提示 |
| 4 | 命令面板 MRU | 执行命令时记录 id 到 localStorage（`palette-mru`，上限 8，去重置顶）；面板排序 = MRU 优先 + 评分 | 用过的命令下次打开置顶，带「最近」标 |

非目标：反链未链接提及（Unlinked mentions）、随机漫游历史记录与排除范围、撤销移动。

## 1. 后端

- `getRandomNote()`：`SELECT id FROM notes WHERE deleted_at IS NULL ORDER BY RANDOM() LIMIT 1` → `getNote(id)`；无笔记返回 null。
- `listBacklinks` 增强：单行 `context` 之外计算 `contextFull`——以命中行为中心取 [i-3, i+3] 行，剔除首尾空行后以 `\n\n` 连接（保留内部空行分隔段落），截 600 字。
- 路由：`GET /notes/random` 挂在 `/notes/:id` 之前（Express 5 不会把 random 当 :id？——会。必须放在参数路由之前注册，测试覆盖）。
- 版本号 0.5.0。

## 2. 前端

- **反链展开**：`bl-item` 右侧加 ▸/▾ 切换按钮；展开态渲染 `contextFull`（pre-wrap 多行小字块）。点击主体仍是「跳转+定位」。
- **笔记拖拽**：NoteList `note-item` 加 `draggable`，dragstart 写 `dataTransfer.setData('application/x-jz-note', String(id))`；Sidebar 笔记本条目 dragover 时检查 `types` 含该类型才 preventDefault + 高亮，drop 读 id → `api.updateNote(id, { notebookId })` → 刷新列表/统计。与现有笔记本拖拽（`text/plain` 隐式）互不干扰：笔记本拖拽不加自定义类型。
- **随机漫游**：App `openRandom()`；顶栏 🎲；palette 注册。
- **MRU**：palette 命令 run 包装层写 localStorage；排序 `mruIndex ?? Infinity` 先于 score；最近命令标题前加「⏱」。

## 3. 测试计划（test/v05.test.mjs）

1. random：建 5 篇 → 连续 20 次随机全部命中既有活跃笔记 id 集合；软删 1 篇后 20 次不再命中它。
2. random 空库（独立 DATA_DIR 的第二个 app 实例）→ 404 语义（返回 200 + null？决定：200 + `{"note": null}`，前端提示「还没有笔记」）。
3. 反链 contextFull：三段式引用（命中行居中）→ 展开文本含前一行与后一行；首尾空行被剔除。
4. `GET /notes/random` 不被 `/notes/:id` 吞掉（顺序回归）。

## 4. 风险与对策

| 风险 | 对策 |
|---|---|
| `/notes/random` 与 `/notes/:id` 路由冲突 | random 先注册 + 专项测试 |
| 两种拖拽类型互踩 | 笔记本拖拽维持无自定义类型；笔记拖拽独占 `application/x-jz-note`；drop 目标按 type 分流 |
| contextFull 过长 | 600 字截断 + 前端 max-height 滚动 |
