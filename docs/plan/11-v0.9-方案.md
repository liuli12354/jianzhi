## 1. 关键决策

1. **日期分组**：段序遵循调研结论（Invalid 不可能——正则保证格式；Overdue/Today/Future/Undated 四段 + 已完成段）；段内 `due` 升序、Undated 按更新时间。切换控件 = `.seg` 分段按钮。
2. **标签页持久化**：`note-tabs-v1` 存 `{tabs, activeId}`；恢复时不自动打开全部内容，激活签走 `openNote`（笔记已删 → toast + 移除该签）。Pin：`pinned` 标记 + 关闭确认（固定签在拖拽排序中视为一组靠前）。
3. **模板**：模板笔记本名固定「模板」（icon 📄，惰性创建、可正常编辑）；实例化时替换 `{{date}}`（本地日期）/`{{time}}`（HH:mm）/`{{title}}`（新建笔记派生标题，替换留空）。入口：命令面板 + 列表头 📄 图标按钮。
4. **拼音匹配**：`pinyin(title, { pattern: 'first', toneType: 'none', type: 'array' }).join('')` 得到首字母串，作为 `fuzzyScore` 的附加匹配域（与标题原文取最优）；模块懒加载失败时静默降级为纯文本匹配。
