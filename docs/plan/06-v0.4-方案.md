## 0. 范围与验收标准

| # | 优化项 | 关键决策 | 验收标准 |
|---|---|---|---|
| 1 | 拖拽三区判定 + 兄弟排序 | 目标条目上 25% = 前插线、下 25% = 后插线、中 50% = 嵌套；`moveNotebook(id, parentId, position)` + 兄弟按步长 10 重编号 | 可把笔记本拖到兄弟前/后（排序持久）、可嵌套、防环仍生效、非法 position 收敛 |

非目标：跨父级拖拽时的复杂动画、反链整段上下文开关（列 v0.5）。

## 1. 后端：兄弟排序

`moveNotebook(id, parentId, position)`：
1. 防环校验沿用 v0.3（沿父链向上遍历）。
2. 取目标父级下的兄弟集合（排除自身），把 id 插入 position（clamp 到 0..len）。
3. 事务内按 `(i+1)*10` 重编号兄弟 `sort_order`，同时更新各自行（含移动者的 parent_id）——用「整组重编号」避免中点碰撞与步长耗尽问题（个人库兄弟数小，成本可忽略）。
4. `position` 非有限数字 → 400；越界 → clamp。

API：`PATCH /notebooks/:id` 传 `{ parentId, position? }`。`GET /notebooks` 已按 `sort_order, id` 排序，前端无需改动排序逻辑。

## 2. 前端：三区拖拽

- `dragover` 时按 `e.clientY` 相对条目矩形分三区，写 `dropState = { id, zone: 'before'|'after'|'nest' }`；样式：插入线（before/after，伪元素横线）与嵌套高亮（nest）。
- `drop` 换算：`before` → target 在兄弟中的原位（剔除拖拽者后）；`after` → 原位+1；`nest` → 目标子级末尾。均由侧栏树结构就地计算。
- 悬停展开：dragover 对「有子级且折叠」的目标起 500ms 定时器，离开/换目标即清。
- 根区域（提升为顶级）保留，position 取末尾。

## 3. 命令面板评分

```ts
score = 前缀 0 ｜ 子串 1 + idx*0.01 ｜ 子序列 50 + 文本长*0.01 ｜ 不命中 ∞
```
命令对 title 评分；笔记取 `min(score(title), score(excerpt)+5)`。结果按分数升序稳定排序（同组内保持原序）。空 query 保持默认顺序。

## 4. 反链定位

- Editor 反链点击 → `onOpenBacklink(id, context)`；App：`openNote(id)` 后 `window.dispatchEvent(new CustomEvent('jz:locate', { detail: { noteId, text } }))`。
- Editor `useEffect` 监听：匹配当前笔记后——分屏/预览态在 `.md-pane` 找包含文本的元素 `scrollIntoView + .flash`；纯编辑态按行号计算 `textarea.scrollTop` 并给 textarea 加 `.flash-outline` 短暂高亮。CSS `@keyframes flash` 1.2s 后自动移除。

## 5. 测试计划（test/v04.test.mjs）

- 三兄弟 A/B/C → C 移到 position 0 → 顺序 [C,A,B] 且 sort_order=10/20/30。
- B 嵌套入 C → C 的子级末尾；再调 position clamp。
- 移入自己的子级 → 400（回归）；position 传 NaN → 400。
- 大 position 越界 → 落到末尾。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 重编号并发/中途失败 | 单事务包裹整组更新 |
| 三区判定误触（行高低） | 条目最小高度 30px；上下各留 25%（≥7px） |
