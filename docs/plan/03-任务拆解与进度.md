## 浏览器实测记录（2026-09-13，生产模式 http://localhost:4321）

**通过用例**：新建笔记本 → 新建笔记（工具栏/自动保存/标题派生）→ 分屏 Markdown 渲染（标题/表格/代码块/待办/引用/双链）→ Ctrl+K 搜索（关键词高亮）→ 双链跳转 → 反向链接面板 → 标签筛选 → 回收站全流程（软删除→恢复→再删除→彻底删除→空态）→ 确认弹窗 → 暗色/浅色主题切换
**结果**：全部通过；截图存档 `docs/verify/`（01-主界面-浅色-分屏编辑器 / 02-全局搜索-关键词高亮 / 03-使用技巧-反向链接-暗色）

**实测发现并已修复的 4 个缺陷**：
1. `POST /api/notes` 忽略 `pinned/starred` 字段 → createNote 补齐
2. 空标题笔记不派生标题（服务端创建时即填「无标题」堵死派生路径）→ 服务端允许空标题，前端从正文首行派生（对齐 Notion 体验）
3. 有笔记时列表无「新建」按钮（只能靠快捷键）→ 列表头部加「＋ 新建」
4. 测试脚手架问题（非应用缺陷）：Git Bash 下 curl 命令行中文按 GBK 传输导致种子数据乱码 → 清库，改用 UTF-8 种子脚本 `scripts/seed.mjs`；另经 Node 端到端回环验证应用 UTF-8 链路无误
