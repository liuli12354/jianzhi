## 0. 范围与验收标准

| # | 功能 | 关键决策 | 验收标准 |
|---|---|---|---|
| 1 | 任务汇总内勾选回写 | `POST /notes/:id/task-toggle {lineIndex, checked, line}`；服务端校验目标行仍是该任务（内容漂移 → 400「内容已变化」），回写走 `updateNote`（自动生成版本快照）；弹窗内点 ☐/☑ 即改源笔记 + Toast 撤销 | 勾选后源笔记内容变更；漂移场景报错不误写 |
| 2 | 提及一键转链 | 未链接提及行加「转为链接」按钮 → `POST /notes/:id/link-mention {title}`；服务端在**非代码块行**替换首个裸标题为 `[[title]]`（fence 追踪 + 行内代码剥离） | 转链后该提及从 unlinked 消失、进入 backlinks |
| 3 | 未链接提及跳过代码块 | 扫描行时追踪 ``` /~~~ 围栏状态，围栏内与行内代码 `` ` ` `` 中的提及不计入 | 围栏内标题不误报 |
| 4 | Toast 操作撤销 | Toast 组件支持动作按钮（存在动作时 5s 时长）；应用于：移入回收站→恢复、笔记换笔记本→移回、笔记本拖拽→按原 parent+position 移回、任务勾选→翻转回去 | 四个场景均出现「撤销」且执行正确 |

非目标：提及转链的批量操作、任务截止日期/优先级字段、撤销多级历史。

## 1. 后端

- `toggleNoteTask(noteId, lineIndex, checked, lineText)`：行号越界/非任务行/内容漂移分别报错；替换 `[ ]↔[x]` 后走 updateNote。
- `linkifyMention(noteId, title)`：逐行扫描（fence 追踪），首个围栏外含裸标题（lookbehind `(?<!\[)` / `(?!\])`）的行做替换；无可转换 → error。
- `listUnlinkedMentions`：fence 追踪 + 行内代码剥离后再做裸匹配。
- 路由与版本：`POST /notes/:id/task-toggle`、`POST /notes/:id/link-mention`；0.7.0。

## 2. 前端

- **Toast**：`showToast(msg, action?)`；动作按钮渲染在 toast 右侧；App 四处接入撤销（回收站/换笔记本/拖拽移动/任务勾选）。
- **TasksModal**：任务行左侧 ☐/☑ 变为可点击按钮（停止冒泡，行点击仍是定位）→ toggle → 刷新弹窗数据 + 撤销 toast；props 增加 `onToast`。
- **Editor**：未链接提及行加「转为链接」小按钮 → 成功后同时刷新 mentions 与 backlinks（提及应移入反链）。
- 任务行文本剥离任务标记后再匹配预览（v0.6 已做）。

## 3. 测试计划（test/v07.test.mjs）

1. task-toggle：正常翻转（内容与版本快照变化）；lineText 漂移 → error；非任务行 → error；404。
2. linkify：围栏内含标题 + 围栏外裸标题 → 只转围栏外首个；转链后再调 → error「未找到」；转链后 backlinks 命中。
3. unlinked：围栏内标题 + 行内代码 `` `标题` `` → 不计入；围栏外裸提及仍命中。

## 4. 风险与对策

| 风险 | 对策 |
|---|---|

| 撤销嵌套调用 toast 抖动 | 撤销动作复用同一 showToast，动作只在首次出现 |
