## 0. 范围与验收标准

| # | 功能 | 关键决策 | 验收标准 |
|---|---|---|---|
| 1 | 搜索结果定位闭环 | Ctrl+K 结果打开笔记后定位到命中片段（FTS snippet 剥离高亮标记作为 locate 文本；LIKE 模式用查询词） | 搜索→打开→闪烁命中处 |
| 2 | 任务优先级 ⭐ | 任务文本内 `⭐` = 高优先级（对齐调研的 emoji-in-line 惯例，取简不做四档）；listAllTasks 解析 `priority` 字段；日期分组段内 ⭐ 在前；行内显示 ⭐ chip | ⭐ 任务在段内置顶且有标识 |
| 3 | 侧栏日历聚合任务 | 新端点 `GET /api/calendar/:y/:m` 返回 `{journalDates, taskDue: {date, count}}`；日历格子上任务到期显示橙色角标 | 有到期任务的日期显示标记 |
| 4 | 快速捕获 | 顶栏 ⚡ 按钮 + 面板命令；弹层 textarea，Ctrl+Enter 保存到未分类，支持 `#标签` 行内语法（首行内 `#xx` 解析为标签） | 保存后笔记出现且带标签 |
| 5 | 工具栏 📅 | 编辑器工具栏新增 📅 按钮，插入今天日期（便于任务标 📅） | 点击后光标处出现当日日期 |

非目标：任务四档优先级（🔺⏫🔼）、日历拖拽改期、快速捕获多行富文本。

## 1. 关键决策

1. **优先级**：单档 ⭐（高）。`listAllTasks` 每行解析 `⭐` → `priority: 1`；排序在现有 due 升序内先 ⭐ 后普通；日期分组视图与笔记分组视图共用该排序；行内 chip ⭐ 常显。
2. **搜索定位**：`SearchModal.onOpen(id, locateText)`——FTS 模式取 `snippet` 剥离 `\u0001/\u0002` 标记并截取命中词附近 60 字；LIKE 模式用原始 q。App 复用 `locateReq` 机制。搜索弹窗不再直接 setView({kind:'all'}) 后丢上下文。
3. **日历聚合**：一条 SQL 出任务到期分布（`journal_date` 思路同理）：`SELECT substr(?)` 从任务文本解析的 due 落在月份内的计数。日历格子已有 journal 圆点，任务角标用橙色 `•n`。
4. **快速捕获**：独立轻弹层（顶部居中小卡）；`#标签` 解析仅取正文前 200 字符内的 `#[^\s#]+`（去行首标题干扰），保存后 toast + 可选「打开」。Ctrl+Enter 保存、Esc 关闭。

## 2. 后端

- `listAllTasks()`：增加 `priority`（⭐ → 1，否则 0）；同段排序 `priority desc, due asc`。
- 新增 `getCalendarMonth(y, m)`：`{ journalDates: string[], taskDue: Record<date, count> }`（journal 复用 listJournalMonth；taskDue 遍历活跃任务文本中的 `📅` 日期聚合）。
- 路由：`GET /calendar/:y/:m`；版本 1.0.0。

## 3. 测试计划（test/v10.test.mjs）

1. priority：`- [ ] ⭐ 优先任务` / 普通任务 → priority 1/0；任务行其余字段不受影响。
2. calendar：建两篇日记（本月不同日）+ 两任务 📅 落在本月 → journalDates 与 taskDue 计数正确；越界月份 400。
