## 1. 后端

- `listUnlinkedMentions(noteId)`：按 `search_text LIKE %title%` 取候选（≤200），JS 端用与 `listBacklinks` 相同的 wiki 正则过滤掉「已链接」的笔记，剩余即未链接提及；附带单行 `context`（复用反链的命中行提取，命中模式为裸标题）。
- `listAllTasks()`：遍历活跃笔记（排除回收站），逐行匹配 GFM 任务 `/^\s*(?:[-*+]|\d+\.)\s+\[( |x|X)\]\s+(.*)$/`；返回 `{ noteId, noteTitle, text, checked, lineIndex, line }` 上限 500；前端分组与筛选。
- 标签：`renameTag(id, name)`——名称已存在则**合并**（`UPDATE OR IGNORE note_tags SET tag_id=target WHERE tag_id=source` → 删源标签）；`deleteTag(id)`。注意 name 唯一约束与空白裁剪、40 字上限。
- 路由：`GET /notes/:id/unlinked`（两段路径，与 `/notes/random` 无冲突）、`GET /tasks`、`PATCH /tags/:id`、`DELETE /tags/:id`；版本号 0.6.0。

## 2. 前端

- **未链接提及**：Editor 反链面板下方「💬 未链接提及（N）」分组；条目 = 笔记标题 + 提及行摘录，点击走 `onOpenBacklink(id, context)` 复用定位闪烁。
- **任务弹窗**：`TasksModal`（640px）；顶栏「✅ 任务」+ 面板命令「打开任务汇总」；筛选 tab（未完成/已完成/全部）；按笔记分组（组头=笔记标题，点击定位笔记）；任务行 = 状态符 + 文本，点击 → 打开笔记 + `locateReq` 定位该行。
- **标签管理**：标签 chip 包一层 `.tag-wrap`，hover 显示 ✎ / 🗑；✎ → chip 原位变输入框（回车确认、Esc 取消）；🗑 → 确认弹窗；合并语义与后端一致（重名即合并）。
- **面包屑**：`view.kind==='notebook'` 时 `nl-title` 渲染路径链（`parentOf` 回溯）；分隔符「/」。
- **任务徽章**：`countTasks(content)` 工具函数（复用与后端一致的正则），`ni-meta` 中显示 `☑ 2/5`。

## 3. 测试计划（test/v06.test.mjs）

1. 未链接提及：三笔记（裸提及/已链接/无提及）→ 只裸提及出现，已链接者不出现在 unlinked 但出现在 backlinks。
2. 任务聚合：含 `- [ ]`/`- [x]`/非任务行的笔记 → 解析正确；软删笔记的任务不出现。
3. 标签：重命名 → 旧名消失新名生效；重命名到已存在名 → 合并（两笔记共享同一标签 id）；删除 → note_tags 清空。
4. 校验：空名/超长名 400。

## 4. 风险与对策

| 风险 | 对策 |
|---|---|
