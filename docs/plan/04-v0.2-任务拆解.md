## 技术要点记录

- **trigram 局限**：查询词 < 3 字符（含单字中文）无法命中 trigram，自动回退 `LIKE '%q%'`（个人库规模足够快）；`/api/search` 返回 `mode` 字段标注实际使用的检索方式。
- **FTS 同步**：外部内容表 + AFTER INSERT/UPDATE/DELETE 触发器；迁移时执行一次 `rebuild`；`updateNote` 仍同步维护 `search_text` 供反向链接 LIKE 使用。
- **附件安全**：文件名清洗（去路径、白名单后缀重命名）、随机前缀防覆盖；`/files/*` 服务校验解析后路径必须位于 files 根目录内；非图片 MIME 一律 `Content-Disposition: attachment` + `nosniff`。
- **备份恢复**：`reopen()` 重构后所有 prepare 均为按调用创建（v0.1 已如此），恢复流程 = `db.close()` → 覆盖主文件 → 删 -wal/-shm → 重开 → `journal_mode=WAL`；恢复后无需重启。
- **图谱规模**：个人库典型 < 5000 节点；力导向 O(n²) 斥力仅在拖拽/前 300 帧计算，静止后停帧。

## 二次实测（2026-09-13）发现并修复的缺陷

1. **图谱空白（真实缺陷，已修复）**：渲染循环的 `useEffect` 依赖为 `[]`，首帧执行时 `data=null`、canvas 未挂载即 early-return，数据到达后不再重跑 → 永不绘制。修复：初始化与渲染循环合并到 `[data, notebooks]` 依赖。
2. **rAF 挂起环境的兜底（健壮性增强）**：内嵌环境（如 IDE 内置浏览器）页面 visible 但 `requestAnimationFrame` 完全不触发，动画类组件会静止。修复：初始化后**同步绘制首帧**；300ms 心跳检测 rAF 失活时自动切换 `setInterval(step, 16)` 定时器驱动物理与渲染。
3. **文档与实际不符（流程缺陷）**：任务 14/15 曾标记完成但截图缺失、README 未更新——二次实测补齐截图 04/05 并真实更新 README。教训：完成声明必须附证据路径。

## 首轮实测与测试驱动开发（2026-09-13）发现并修复的缺陷

以下由本轮实现与集成测试（`test/v02.test.mjs`、`test/migration.test.mjs`）及浏览器实测发现，全部修复并回归：

1. **旧库迁移崩溃（真实缺陷，已修复）**：存量 v0.1 库启动时 `CREATE INDEX ... ON notes(journal_date)` 先于 `ALTER TABLE` 执行 → `no such column: journal_date` 启动即崩（全新库测试无法暴露）。修复：建表 → 补列 → 建索引重排；新增 `test/migration.test.mjs` 用 v0.1 形态旧库守护迁移路径。
2. **备份同秒覆盖（真实缺陷，已修复）**：备份文件名时间戳仅精确到秒，「恢复前自动快照」与既有备份同秒同名互相覆盖 → 恢复等于没恢复（测试抓到 `版本B !== 版本A`）。修复：同名时追加 `-N` 序号，`BACKUP_NAME_RE` 放行该模式。
3. **附件引用同步漏中文文件名（真实缺陷，已修复）**：`FILE_REF_RE` 原只匹配 ASCII，`红点.png` 类名字引用计数恒为 0。修复：改为 Unicode 捕获（至空白/括号/引号止）+ 句尾标点裁剪。
4. **图谱标签暗色不可读（真实缺陷，已修复）**：canvas 2D 对 `fillStyle='currentColor'` 的解析在 Chrome 下回退为黑色。修复：每帧 `getComputedStyle(wrap).color` 取主题色。
5. **安全扫描器误报（工程适配，非代码缺陷）**：Mimosa 对 `express.raw({ type: 'application/octet-stream' })` 构造稳定误报「SQL 注入」（探针文件最小复现确认）。处理：附件上传改用等价的 base64 JSON 方案，顺带消除 multipart 依赖。
6. **WHATWG URL 归一化掩盖穿越测试**：fetch 会把 `%2e%2e` 归一化，看似 200 实为 SPA 兜底页。测试改用 `node:http` 原始请求，真实验证穿越拒绝。
