## 1. 层级笔记本（树）

**数据模型**：`notebooks` 增加 `parent_id INTEGER REFERENCES notebooks(id) ON DELETE SET NULL`。沿用 v0.2 的补列迁移模式（`pragma_table_info` 检测），旧库自动升级；删除父笔记本时子笔记本提升为顶级（与笔记 `SET NULL` 语义一致，数据零丢失）。

**防环**：`updateNotebook({ parentId })` 时沿 parent 链向上遍历，遇到自身即 400「不能将笔记本移动到它自己的子级」。父级不存在同样 400。

**子树聚合**：选中父笔记本时展示整个子树的笔记：

```sql
WITH RECURSIVE subtree(id) AS (
  SELECT ? UNION ALL SELECT n.id FROM notebooks n JOIN subtree s ON n.parent_id = s.id
)
... WHERE n.notebook_id IN (SELECT id FROM subtree)
```

侧栏仍显示各节点直接计数（`note_count`），树形缩进 + 折叠箭头，聚合总数在选中时由列表数量体现。

**交互**：
- 拖拽 A 到 B 上 = A 成为 B 的子级；拖到侧栏「笔记本」标题区或根空白 = 提升为顶级。HTML5 原生 DnD（dragstart/dragover/drop），拖拽目标高亮。
- 每节点 hover 动作保持 重命名/删除；新增「＋子级」按钮（避免纯拖拽不可发现）。
- 折叠状态存 localStorage（`nb-folded`）。

## 2. 命令面板（Ctrl+P）

与 Ctrl+K 分工：**K 找内容（FTS 搜索），P 执行动作 / 跳笔记**（Obsidian/VS Code 范式）。

- **动作注册表**：`CommandPalette` 接收 `actions: {id, title, kbd?, run}[]`，由 App 闭包注入现有 handlers（新建笔记/笔记本、今日笔记、图谱、设置、导出 JSON、导出 Markdown ZIP、切换主题、清空回收站、提升为顶级笔记本…）。
- **笔记跳转**：当前活跃笔记列表（前 50，按更新时间）作为第二组。
- **匹配**：query 为空显示全部；非空按大小写不敏感子串过滤，标题前缀命中优先。↑↓ 循环、Enter 执行、Esc 关闭，鼠标 hover 同步高亮。

## 3. 全库导出 Markdown ZIP（零依赖 store ZIP）

`GET /api/export/md` → `jianzhi-md-<日期>.zip`（attachment）。

**结构**：
```
<笔记本名>/<(序号-)标题>.md     # 活跃笔记，未分类进「未分类/」
attachments/<file_name>         # 被引用附件原样归档（保留 YYYYMM 子目录）
```
同名条目自动追加 `(id)` 去重；文件名清洗非法字符（沿用附件 sanitize 规则 + `/` 替换）。

**store ZIP 实现要点**（无 zlib 依赖，条目不压缩只存储）：
- 本地文件头 `PK\x03\x04` + 版本 20 + **通用标志 bit11（UTF-8 文件名）** + method 0 + CRC32 + 原始长度；
- 中央目录 `PK\x01\x02` + EOCD `PK\x05\x06`；不写目录占位条目（标准解压器均接受）；
- CRC32 查表实现（poly 0xEDB88320）；路径分隔符一律 `/`。

前端在顶栏「导出」下拉旁新增按钮，下载后 toast 提示。

## 4. 反向链接上下文

`listBacklinks` 查询加 `content`，JS 提取第一条包含 `[[标题]]` 的非空行：剥离行首 Markdown 标记、截 100 字、命中处保留原文。`Backlink` 类型加 `context?: string`；编辑器反链面板以次要行渲染，点击仍整篇打开。
