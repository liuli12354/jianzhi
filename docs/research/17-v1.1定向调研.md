## 一、活动热力图（GitHub Contributions 惯例）

来源：GitHub 官方文档帮助中心 + 社区实现（rudrodip/gitmap、21st.dev Contribution Graph、fwdtools 零依赖实现，经 WebSearch 汇总）。

| 维度 | 惯例 |
|---|---|
| 色阶 | **5 档离散分桶**（非连续渐变）：0 空 / 1-3 / 4-6 / 7-9 / 10+（社区另有 1-2/3-5/6-10/11+ 变体，以 GitHub 官方值为准） |
| 浅色色值 | `#ebedf0`（空）→ `#9be9a8` → `#40c463` → `#30a14e` → `#216e39` |
| 暗色色值 | `#161b22`（空）→ `#0e4429` → `#006d32` → `#26a641` → `#39d353` |
| 格子 | 约 10px，圆角 2-3px，间距 3-4px；周列布局（7 行 × 列） |
| tooltip | 「N contributions on <日期>」格式（单数/零也要区分） |
| 统计口径 | 产生一条可计活动即 +1（对简知 = 一次内容保存/变更） |

## 二、日历当日详情（日历应用惯例）

来源：Google Calendar / 苹果日历 / 滴答清单交互模式（前轮调研 16 号文件已引用）。

- 点击日期格子（有事件/任务时）→ 弹出**当日详情层**，列出当日条目（任务行可点击跳转源）。
- 无条目的空白日默认「新建」语义（简知已有：点击 = 打开/新建当日日记）。

## 三、多档优先级（沿用 doc 16 已确认结论）

Obsidian Tasks 官方五档：🔺最高 / ⏫高 / 🔼中 / 无标记 / ⏬低，emoji 追加在任务描述末尾；同日期内高优先在前。简知 v1.1 数值化为 3/2/1/0/-1，并保留 v1.0 的 ⭐ 兼容映射为 1。

## 四、落地建议汇总

1. 热力图按 GitHub 官方 5 档分桶（1-3/4-6/7-9/10+），色值直接用官方案例值（浅/暗各一套）。
2. tooltip 中文格式「N 月 D 日 · N 次活动」（对齐「N contributions on date」）。
3. 格子 10px / 圆角 2px / 间距 3px，CSS Grid 周列布局。
4. 当日详情层仅在有任务/日记时弹出；任务行点击定位源笔记。
5. 优先级 chip 分档着色（🔺红/⏫橙/🔼黄/⏬灰蓝），无标记不显示 chip。
